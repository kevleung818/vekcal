# Atrium

Atrium is a demonstration of a Hong Kong health-information venue. It publishes educational writing by fictional licensed professionals, takes a simulated membership fee from readers, and keeps brand placements in a separate, labelled layer.

It does not give medical advice, join a consultation, or handle a consultation fee. Booking stops at a screen that would open the clinic’s own system. Honorary points cannot be spent on discounts, priority, exposure, or patient stories.

The participation terms are a draft for a solicitor. The people in the directory are not real clinicians.

```sh
cd atrium
npm install
npm test
npm run dev
```

Open http://127.0.0.1:5179. Use **View as** to walk through a visitor, a member, a licensed professional, a reviewer, and a brand. The demonstration is stored in the browser. Reset it from the strip under the header.
